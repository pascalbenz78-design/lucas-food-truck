# Eigene Grafiken

Lege hier echte Sprites ab (PNG oder SVG) und trage sie in `src/assets/assetMap.ts` unter
`OVERRIDES` ein, z. B.:

```ts
ing_salad: { kind: 'image', url: 'assets/salat.png' },
```

Alle verfügbaren Schlüssel und ihre Sollgrössen: siehe Haupt-README, Abschnitt
«Platzhalter-Grafiken ersetzen».
